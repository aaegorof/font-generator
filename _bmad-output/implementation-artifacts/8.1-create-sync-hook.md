# Story 8.1: Create Sync Hook

## Description

Создать React hook `useSupabaseSync` для автоматической синхронизации Zustand store с Supabase. Hook должен отслеживать изменения в store, сохранять их в Supabase с debouncing и загружать данные при монтировании.

## User Story

**As a** авторизованный пользователь  
**I want** чтобы мои изменения автоматически сохранялись в облако  
**So that** я не терял свою работу и мог работать с разных устройств

## Goals

- Создать hook для синхронизации store с Supabase
- Реализовать debounced автосохранение (2 секунды)
- Реализовать загрузку данных при монтировании
- Обеспечить работу только для авторизованных пользователей
- Обработать конфликты и ошибки

### Implementation (`src/hooks/useSupabaseSync.ts`)

```typescript
import { useEffect, useRef, useState } from 'react'
import { useStore } from '../store/useStore'
import { supabase } from '../lib/supabase'

export interface UseSupabaseSyncReturn {
  syncing: boolean
  lastSynced: Date | null
  error: Error | null
  forceSave: () => Promise<void>
}

export function useSupabaseSync(userId: string | null): UseSupabaseSyncReturn {
  const [syncing, setSyncing] = useState(false)
  const [lastSynced, setLastSynced] = useState<Date | null>(null)
  const [error, setError] = useState<Error | null>(null)

  const saveTimeoutRef = useRef<NodeJS.Timeout>()
  const lastStateRef = useRef<string>()

  // Subscribe to store changes
  useEffect(() => {
    if (!userId) return

    const unsubscribe = useStore.subscribe((state) => {
      // Get only persisted state
      const persistedState = {
        settings: state.settings,
        textInputs: state.textInputs,
        fonts: state.fonts,
        images: state.images,
        disabledImages: state.disabledImages,
        favorites: state.favorites,
        toolbarOpen: state.toolbarOpen,
        layerFontPins: state.layerFontPins,
      }

      const stateJson = JSON.stringify(persistedState)

      // Skip if state hasn't changed
      if (stateJson === lastStateRef.current) return
      lastStateRef.current = stateJson

      // Debounced save
      if (saveTimeoutRef.current) {
        clearTimeout(saveTimeoutRef.current)
      }

      saveTimeoutRef.current = setTimeout(() => {
        saveToSupabase(userId, persistedState)
      }, 2000)
    })

    return () => {
      unsubscribe()
      if (saveTimeoutRef.current) {
        clearTimeout(saveTimeoutRef.current)
      }
    }
  }, [userId])

  // Load data on mount
  useEffect(() => {
    if (!userId) return
    loadFromSupabase(userId)
  }, [userId])

  const saveToSupabase = async (userId: string, state: any) => {
    setSyncing(true)
    setError(null)

    try {
      const { error: saveError } = await supabase
        .from('user_profiles')
        .update({
          settings: state.settings,
          text_inputs: state.textInputs,
          toolbar_open: state.toolbarOpen,
          layer_font_pins: state.layerFontPins,
          disabled_images: state.disabledImages,
          updated_at: new Date().toISOString(),
        })
        .eq('id', userId)

      if (saveError) throw saveError

      setLastSynced(new Date())
    } catch (err) {
      console.error('Error saving to Supabase:', err)
      setError(err as Error)
    } finally {
      setSyncing(false)
    }
  }

  const loadFromSupabase = async (userId: string) => {
    try {
      const { data, error: loadError } = await supabase
        .from('user_profiles')
        .select('*')
        .eq('id', userId)
        .single()

      if (loadError) throw loadError
      if (!data) return

      // Update store with loaded data
      const store = useStore.getState()

      if (data.settings) {
        store.updateSettings(data.settings)
      }

      // Text inputs, fonts, images, etc. will be loaded in separate stories

      setLastSynced(new Date(data.updated_at))
    } catch (err) {
      console.error('Error loading from Supabase:', err)
      setError(err as Error)
    }
  }

  const forceSave = async () => {
    if (!userId) return

    const state = useStore.getState()
    const persistedState = {
      settings: state.settings,
      textInputs: state.textInputs,
      fonts: state.fonts,
      images: state.images,
      disabledImages: state.disabledImages,
      favorites: state.favorites,
      toolbarOpen: state.toolbarOpen,
      layerFontPins: state.layerFontPins,
    }

    await saveToSupabase(userId, persistedState)
  }

  return {
    syncing,
    lastSynced,
    error,
    forceSave,
  }
}
```

### Debouncing Strategy

- **2 секунды** — оптимальный баланс между UX и нагрузкой на сервер
- При каждом изменении таймер сбрасывается
- Последнее изменение сохраняется через 2 сек после последнего изменения

### State Comparison

Для избежания лишних сохранений:

- Сравниваем JSON.stringify текущего и предыдущего состояния
- Сохраняем только если есть реальные изменения
- Игнорируем transient state (tiles, modals, etc.)

## Performance Considerations

### Optimization Strategies

1. **Selective Sync**: Синхронизировать только измененные поля
2. **Batch Updates**: Группировать множественные изменения
3. **Skip Transient State**: Не синхронизировать UI state (modals, loading, etc.)
4. **Compression**: Для больших данных использовать compression (future)

### Memory Management

- Очищать timeout при unmount
- Отписываться от store subscription
- Не хранить большие объекты в refs

## Error Handling

### Network Errors

```typescript
try {
  await saveToSupabase(userId, state)
} catch (err) {
  if (err.message.includes('network')) {
    // Retry after 5 seconds
    setTimeout(() => saveToSupabase(userId, state), 5000)
  }
}
```

### Conflict Resolution

Если данные изменились на сервере:

- **Strategy 1**: Last write wins (простой подход)
- **Strategy 2**: Merge changes (сложнее, future enhancement)
- **Strategy 3**: Показать конфликт пользователю (future enhancement)
