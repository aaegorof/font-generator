## User Instructions

### Quick Start (5 minutes)

1. **Get Google Credentials**:
   - Go to https://console.cloud.google.com/
   - Create OAuth 2.0 Client ID
   - Copy Client ID and Client Secret

2. **Update .env**:

   ```bash
   SUPABASE_AUTH_EXTERNAL_GOOGLE_CLIENT_ID=your-actual-client-id.apps.googleusercontent.com
   SUPABASE_AUTH_EXTERNAL_GOOGLE_SECRET=your-actual-secret
   VITE_GOOGLE_CLIENT_ID=your-actual-client-id.apps.googleusercontent.com
   ```

3. **Restart Supabase**:

   ```bash
   npx supabase stop
   npx supabase start
   ```

4. **Test**:

   ```bash
   ./scripts/test-google-oauth.sh
   ```

5. **Test in Browser**:
   ```
   http://127.0.0.1:54321/auth/v1/authorize?provider=google&redirect_to=http://localhost:5173
   ```

See `docs/GOOGLE_OAUTH_SETUP.md` for complete step-by-step instructions.

## OAuth Flow Diagram

```
User clicks "Sign in with Google"
         ↓
Frontend redirects to Supabase Auth
http://127.0.0.1:54321/auth/v1/authorize?provider=google
         ↓
Supabase redirects to Google OAuth
https://accounts.google.com/o/oauth2/v2/auth?client_id=...
         ↓
User authorizes in Google
         ↓
Google redirects to Supabase callback
http://127.0.0.1:54321/auth/v1/callback?code=...
         ↓
Supabase processes callback, creates session
         ↓
Supabase redirects to frontend
http://localhost:5173#access_token=...&refresh_token=...
         ↓
Frontend extracts tokens from URL hash
         ↓
User is authenticated ✅
```

5. Restrict authorized origins to production domains only

## Troubleshooting Quick Reference

| Error                     | Solution                                                    |
| ------------------------- | ----------------------------------------------------------- |
| "provider is not enabled" | Restart Supabase: `npx supabase stop && npx supabase start` |
| "redirect_uri_mismatch"   | Check redirect URIs in Google Console match exactly         |
| "invalid_client"          | Verify Client ID and Secret in `.env` are correct           |
| "App not verified"        | Normal for development, click "Advanced" → "Go to app"      |

Full troubleshooting guide: `docs/GOOGLE_OAUTH_SETUP.md` → "Troubleshooting" section
