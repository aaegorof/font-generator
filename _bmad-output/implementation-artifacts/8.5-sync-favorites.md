# Story 8.5: Sync Favorites

## Description

Реализовать синхронизацию избранных тайлов между Zustand store и Supabase таблицей `user_favorites`. Каждый favorite содержит полный snapshot тайла с настройками.

## User Story

**As a** авторизованный пользователь  
**I want** чтобы мои избранные тайлы синхронизировались с облаком  
**So that** я мог получить к ним доступ с любого устройства

## Goals

- Синхронизировать список избранных с таблицей `user_favorites`
- Сохранять полный snapshot тайла (изображение, шрифт, текст, настройки)
- Обеспечить двустороннюю синхронизацию (load и save)
- Корректно обрабатывать добавление и удаление избранных

## Acceptance Criteria

### Must Have

- [x] Favorites синхронизируются с Supabase
- [x] При добавлении в избранное — запись создается в `user_favorites`
- [x] При удалении из избранного — запись удаляется из `user_favorites`
- [x] При логине favorites загружаются из Supabase
- [x] Полный snapshot тайла сохраняется (tile + textInputs + settings)

### Should Have

- [ ] Batch операции для множественных изменений (future enhancement)
- [x] Валидация данных перед сохранением

## Technical Details

### Favorite Data Structure

```typescript
// Zustand store
interface FavoriteItem {
  id: string
  tile: TileData
  textInput: TextInput
  timestamp: number
}

interface TileData {
  id: string
  imageUrl: string
  fontId: string
  textInputId: string
}

// Supabase user_favorites table
{
  id: UUID,
  user_id: UUID,
  favorite_data: JSONB,  // Full FavoriteItem object
  created_at: TIMESTAMPTZ
}
```

### Favorite Sync Service

Создать `src/services/favoriteSync.ts`:

```typescript
import { supabase } from '../lib/supabase'
import type { FavoriteItem } from '../types'

export class FavoriteSyncService {
  /**
   * Load all favorites for a user
   */
  static async loadFavorites(userId: string): Promise<FavoriteItem[]> {
    try {
      const { data, error } = await supabase
        .from('user_favorites')
        .select('favorite_data, created_at')
        .eq('user_id', userId)
        .order('created_at', { ascending: false })

      if (error) throw error

      return data.map((row) => row.favorite_data as FavoriteItem)
    } catch (err) {
      console.error('Error loading favorites:', err)
      throw err
    }
  }

  /**
   * Save a new favorite
   */
  static async saveFavorite(userId: string, favorite: FavoriteItem): Promise<void> {
    try {
      // Validate favorite data
      this.validateFavorite(favorite)

      const { error } = await supabase.from('user_favorites').insert({
        user_id: userId,
        favorite_data: favorite,
      })

      if (error) throw error
    } catch (err) {
      console.error('Error saving favorite:', err)
      throw err
    }
  }

  /**
   * Delete a favorite
   */
  static async deleteFavorite(userId: string, favoriteId: string): Promise<void> {
    try {
      const { error } = await supabase
        .from('user_favorites')
        .delete()
        .eq('user_id', userId)
        .eq('favorite_data->id', favoriteId)

      if (error) throw error
    } catch (err) {
      console.error('Error deleting favorite:', err)
      throw err
    }
  }

  /**
   * Validate favorite data
   */
  private static validateFavorite(favorite: FavoriteItem): void {
    if (!favorite.id || typeof favorite.id !== 'string') {
      throw new Error('Invalid favorite id')
    }

    if (!favorite.tile || typeof favorite.tile !== 'object') {
      throw new Error('Invalid favorite tile')
    }

    if (!favorite.tile.id || !favorite.tile.imageUrl || !favorite.tile.fontId) {
      throw new Error('Invalid tile data')
    }

    if (!favorite.textInput || typeof favorite.textInput !== 'object') {
      throw new Error('Invalid favorite textInput')
    }

    if (!favorite.textInput.id || typeof favorite.textInput.text !== 'string') {
      throw new Error('Invalid textInput data')
    }

    if (typeof favorite.timestamp !== 'number') {
      throw new Error('Invalid favorite timestamp')
    }
  }
}
```

### Update Store Actions

Обновить `src/store/useStore.ts`:

```typescript
import { FavoriteSyncService } from '../services/favoriteSync'

// Add favorite with sync
addFavorite: (tile: TileData) => {
  const textInput = get().textInputs.find((ti) => ti.id === tile.textInputId)
  if (!textInput) return

  const favorite: FavoriteItem = {
    id: `fav-${Date.now()}-${Math.random().toString(36).substr(2, 9)}`,
    tile,
    textInput,
    timestamp: Date.now(),
  }

  set((state) => ({
    favorites: [favorite, ...state.favorites],
  }))

  // Sync to Supabase if user is logged in
  const userId = getCurrentUserId()
  if (userId) {
    FavoriteSyncService.saveFavorite(userId, favorite).catch(console.error)
  }
},

// Remove favorite with sync
removeFavorite: (id: string) => {
  set((state) => ({
    favorites: state.favorites.filter((f) => f.id !== id),
  }))

  // Sync to Supabase if user is logged in
  const userId = getCurrentUserId()
  if (userId) {
    FavoriteSyncService.deleteFavorite(userId, id).catch(console.error)
  }
},
```

```typescript
import { FavoriteSyncService } from '../services/favoriteSync'

const loadUserData = async (userId: string) => {
  try {
    // Load profile
    // ... existing code ...

    // Load fonts
    // ... existing code ...

    // Load images
    // ... existing code ...

    // Load favorites
    const favorites = await FavoriteSyncService.loadFavorites(userId)
    const store = useStore.getState()

    // Replace favorites in store
    favorites.forEach((favorite) => {
      // Check if favorite already exists
      if (!store.favorites.find((f) => f.id === favorite.id)) {
        // Manually add to avoid triggering sync
        store.setState((state) => ({
          favorites: [...state.favorites, favorite],
        }))
      }
    })
  } catch (err) {
    console.error('Error loading user data:', err)
  }
}
```

## Edge Cases

### Case 1: Duplicate Favorites

- Если пользователь пытается добавить тот же тайл дважды
- Разрешить (каждый favorite имеет уникальный ID)
- Или проверять по содержимому и предотвращать дубликаты

### Case 2: Invalid Favorite Data

- Если в БД попали невалидные данные
- Показать ошибку и пропустить невалидный favorite
- Логировать проблему для отладки

### Case 3: Missing Font or Image

- Если favorite ссылается на удаленный шрифт или изображение
- Показать placeholder или ошибку
- Не удалять favorite автоматически

### Case 4: Large Number of Favorites

- Если у пользователя сотни favorites
- Реализовать pagination (future)
- Или lazy loading

## Performance Considerations

### Optimization Strategies
