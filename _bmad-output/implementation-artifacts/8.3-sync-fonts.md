# Story 8.3: Sync Fonts

## Description

Реализовать синхронизацию шрифтов между Zustand store и Supabase таблицей `user_fonts`. Включает Google Fonts, локальные шрифты и загруженные пользователем шрифты.

## User Story

**As a** авторизованный пользователь  
**I want** чтобы мои шрифты (Google Fonts, локальные, загруженные) синхронизировались с облаком  
**So that** они были доступны с любого устройства

## Goals

- Синхронизировать список шрифтов с таблицей `user_fonts`
- Поддержать все типы шрифтов (Google, local, uploaded)
- Обеспечить двустороннюю синхронизацию (load и save)
- Корректно обрабатывать добавление и удаление шрифтов

## Acceptance Criteria

- [x] Локальные шрифты синхронизируются с Supabase

## Technical Details

### Font Data Structure

```typescript
// Zustand store
interface FontDef {
  id: string
  name: string
  source: 'google' | 'local' | 'uploaded'
  category?: string
  isActive?: boolean
  uploadUrl?: string
  fileName?: string
}

// Supabase user_fonts table
{
  id: UUID,
  user_id: UUID,
  font_def: JSONB,  // Full FontDef object
  storage_path: TEXT | null,  // For uploaded fonts
  created_at: TIMESTAMPTZ
}
```

### Font Sync Service

Создать `src/services/fontSync.ts`:

```typescript
import { supabase } from '../lib/supabase'
import type { FontDef } from '../types'
import { DEFAULT_FONTS } from '../utils/fonts'

export class FontSyncService {
  /**
   * Load all fonts for a user
   */
  static async loadFonts(userId: string): Promise<FontDef[]> {
    try {
      const { data, error } = await supabase
        .from('user_fonts')
        .select('font_def, storage_path')
        .eq('user_id', userId)
        .order('created_at', { ascending: true })

      if (error) throw error

      return data.map((row) => ({
        ...row.font_def,
        uploadUrl: row.storage_path ? this.getStorageUrl(row.storage_path) : undefined,
      }))
    } catch (err) {
      console.error('Error loading fonts:', err)
      throw err
    }
  }

  /**
   * Save a new font
   */
  static async saveFont(userId: string, font: FontDef): Promise<void> {
    try {
      // Don't save default fonts
      if (this.isDefaultFont(font)) {
        return
      }

      const { error } = await supabase.from('user_fonts').insert({
        user_id: userId,
        font_def: font,
        storage_path: font.source === 'uploaded' ? font.uploadUrl : null,
      })

      if (error) throw error
    } catch (err) {
      console.error('Error saving font:', err)
      throw err
    }
  }

  /**
   * Update font (e.g., toggle isActive)
   */
  static async updateFont(
    userId: string,
    fontId: string,
    updates: Partial<FontDef>,
  ): Promise<void> {
    try {
      // Get current font_def
      const { data, error: fetchError } = await supabase
        .from('user_fonts')
        .select('font_def')
        .eq('user_id', userId)
        .eq('font_def->id', fontId)
        .single()

      if (fetchError) throw fetchError

      // Merge updates
      const updatedFontDef = { ...data.font_def, ...updates }

      // Update in database
      const { error: updateError } = await supabase
        .from('user_fonts')
        .update({ font_def: updatedFontDef })
        .eq('user_id', userId)
        .eq('font_def->id', fontId)

      if (updateError) throw updateError
    } catch (err) {
      console.error('Error updating font:', err)
      throw err
    }
  }

  /**
   * Delete a font
   */
  static async deleteFont(userId: string, fontId: string): Promise<void> {
    try {
      const { error } = await supabase
        .from('user_fonts')
        .delete()
        .eq('user_id', userId)
        .eq('font_def->id', fontId)

      if (error) throw error
    } catch (err) {
      console.error('Error deleting font:', err)
      throw err
    }
  }

  /**
   * Check if font is a default font
   */
  private static isDefaultFont(font: FontDef): boolean {
    return DEFAULT_FONTS.some((df) => df.id === font.id)
  }

  /**
   * Get public URL for uploaded font
   */
  private static getStorageUrl(path: string): string {
    const { data } = supabase.storage.from('user-fonts').getPublicUrl(path)

    return data.publicUrl
  }
}
```

### Update Store Actions

Обновить `src/store/useStore.ts`:

```typescript
import { FontSyncService } from '../services/fontSync'

// Add font with sync
addFont: (font: FontDef) => {
  set((state) => ({
    fonts: [...state.fonts, font],
  }))

  // Sync to Supabase if user is logged in
  const userId = getCurrentUserId() // Helper function
  if (userId) {
    FontSyncService.saveFont(userId, font).catch(console.error)
  }
},

// Remove font with sync
removeFont: (id: string) => {
  set((state) => ({
    fonts: state.fonts.filter((f) => f.id !== id),
  }))

  // Sync to Supabase if user is logged in
  const userId = getCurrentUserId()
  if (userId) {
    FontSyncService.deleteFont(userId, id).catch(console.error)
  }
},

// Toggle font active with sync
toggleFontActive: (id: string) => {
  set((state) => ({
    fonts: state.fonts.map((f) =>
      f.id === id ? { ...f, isActive: !f.isActive } : f
    ),
  }))

  // Sync to Supabase if user is logged in
  const userId = getCurrentUserId()
  if (userId) {
    const font = get().fonts.find(f => f.id === id)
    if (font) {
      FontSyncService.updateFont(userId, id, { isActive: font.isActive }).catch(console.error)
    }
  }
},
```

### Load Fonts on Login

Обновить `src/hooks/useUserData.ts`:

```typescript
import { FontSyncService } from '../services/fontSync'

const loadUserData = async (userId: string) => {
  try {
    // Load profile
    // ... existing code ...

    // Load fonts
    const fonts = await FontSyncService.loadFonts(userId)
    const store = useStore.getState()

    // Merge with default fonts
    const allFonts = [...DEFAULT_FONTS, ...fonts]

    // Update store
    allFonts.forEach((font) => {
      if (!store.fonts.find((f) => f.id === font.id)) {
        store.addFont(font)
      }
    })
  } catch (err) {
    console.error('Error loading user data:', err)
  }
}
```

### Helper Function

```typescript
import { supabase } from '../lib/supabase'

export async function getCurrentUserId(): Promise<string | null> {
  const {
    data: { session },
  } = await supabase.auth.getSession()
  return session?.user?.id ?? null
}
```

## Edge Cases

### Case 1: Duplicate Fonts

- Если пользователь пытается добавить дубликат
- Проверить по `font.id` перед добавлением
- Показать сообщение "Font already exists"

### Case 2: Deleted Default Font

- Если пользователь удалил дефолтный шрифт
- При следующей загрузке восстановить из DEFAULT_FONTS
- Или не разрешать удаление дефолтных шрифтов

### Case 3: Font Without ID

- Если шрифт не имеет ID
- Сгенерировать ID перед сохранением
- Логировать warning

## Performance Considerations

### Optimization Strategies

1. **Batch Insert**: При загрузке множества шрифтов использовать batch insert
2. **Lazy Loading**: Загружать шрифты по требованию (future)
3. **Caching**: Кэшировать список шрифтов в памяти
4. **Debouncing**: Для toggle isActive использовать debouncing

## Notes

### Data Architecture (IMPORTANT)

- **Supabase = единственный источник правды** для авторизованных пользователей
  - localStorage автоматически очищается после загрузки из Supabase (см. Story 8.1)
  - Все изменения сохраняются только в Supabase
  - Нет конфликтов между localStorage и базой данных

- **CRITICAL**: Используйте `initialLoadComplete` pattern из Story 8.1
  - НЕ подписывайтесь на изменения до завершения загрузки из Supabase
  - Устанавливайте baseline state перед активацией subscription
  - Это предотвращает перезапись базы дефолтными значениями

### Font Sync Details

- В этой story синхронизируются только метаданные шрифтов
- Файлы загруженных шрифтов будут синхронизироваться в Story 9.1
- DEFAULT_FONTS всегда доступны и не сохраняются в БД
- Для uploaded fonts `storage_path` будет заполнен в Story 9.1
