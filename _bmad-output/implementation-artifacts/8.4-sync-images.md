# Story 8.4: Sync Images

## Description

Реализовать синхронизацию изображений между Zustand store и Supabase таблицей `user_images`. Включает метаданные изображений (URL, storage path) без синхронизации самих файлов (файлы будут в Story 9.2).

## User Story

**As a** авторизованный пользователь  
**I want** чтобы мои изображения синхронизировались с облаком  
**So that** они были доступны с любого устройства

## Goals

- Синхронизировать список изображений с таблицей `user_images`
- Поддержать URL-based изображения (DEFAULT_IMAGES)
- Обеспечить двустороннюю синхронизацию (load и save)
- Корректно обрабатывать добавление и удаление изображений

## Acceptance Criteria

### Must Have

## Technical Details

### Image Data Structure

```typescript
// Zustand store
images: string[]  // Array of URLs

// Supabase user_images table
{
  id: UUID,
  user_id: UUID,
  storage_path: TEXT,  // Path in Storage (for uploaded images)
  url: TEXT,           // Public URL
  created_at: TIMESTAMPTZ
}
```

### Image Sync Service

Создать `src/services/imageSync.ts`:

```typescript
import { supabase } from '../lib/supabase'
import { DEFAULT_IMAGES } from '../utils/images'

export class ImageSyncService {
  /**
   * Load all images for a user
   */
  static async loadImages(userId: string): Promise<string[]> {
    try {
      const { data, error } = await supabase
        .from('user_images')
        .select('url')
        .eq('user_id', userId)
        .order('created_at', { ascending: true })

      if (error) throw error

      return data.map((row) => row.url)
    } catch (err) {
      console.error('Error loading images:', err)
      throw err
    }
  }

  /**
   * Save a new image
   */
  static async saveImage(userId: string, url: string, storagePath?: string): Promise<void> {
    try {
      // Don't save default images
      if (this.isDefaultImage(url)) {
        return
      }

      const { error } = await supabase.from('user_images').insert({
        user_id: userId,
        url: url,
        storage_path: storagePath || url, // Use URL as path for external images
      })

      if (error) throw error
    } catch (err) {
      console.error('Error saving image:', err)
      throw err
    }
  }

  /**
   * Delete an image
   */
  static async deleteImage(userId: string, url: string): Promise<void> {
    try {
      const { error } = await supabase
        .from('user_images')
        .delete()
        .eq('user_id', userId)
        .eq('url', url)

      if (error) throw error
    } catch (err) {
      console.error('Error deleting image:', err)
      throw err
    }
  }

  /**
   * Check if image is a default image
   */
  private static isDefaultImage(url: string): boolean {
    return DEFAULT_IMAGES.includes(url)
  }

  /**
   * Get storage path from URL
   */
  static getStoragePathFromUrl(url: string): string | null {
    // Extract storage path from Supabase Storage URL
    const match = url.match(/\/storage\/v1\/object\/public\/user-images\/(.+)/)
    return match ? match[1] : null
  }
}
```

### Update Store Actions

Обновить `src/store/useStore.ts`:

```typescript
import { ImageSyncService } from '../services/imageSync'

// Add image with sync
addImage: (url: string) => {
  set((state) => ({
    images: [...state.images, url],
  }))

  // Sync to Supabase if user is logged in
  const userId = getCurrentUserId()
  if (userId) {
    const storagePath = ImageSyncService.getStoragePathFromUrl(url)
    ImageSyncService.saveImage(userId, url, storagePath).catch(console.error)
  }
},

// Remove image with sync
removeImage: (url: string) => {
  set((state) => ({
    images: state.images.filter((img) => img !== url),
    disabledImages: state.disabledImages.filter((img) => img !== url),
  }))

  // Sync to Supabase if user is logged in
  const userId = getCurrentUserId()
  if (userId) {
    ImageSyncService.deleteImage(userId, url).catch(console.error)
  }
},
```

### Load Images on Login

Обновить `src/hooks/useUserData.ts`:

```typescript
import { ImageSyncService } from '../services/imageSync'

const loadUserData = async (userId: string) => {
  try {
    // Load profile
    // ... existing code ...

    // Load fonts
    // ... existing code ...

    // Load images
    const images = await ImageSyncService.loadImages(userId)
    const store = useStore.getState()

    // Merge with default images
    const allImages = [...DEFAULT_IMAGES, ...images]

    // Update store
    allImages.forEach((url) => {
      if (!store.images.includes(url)) {
        store.addImage(url)
      }
    })
  } catch (err) {
    console.error('Error loading user data:', err)
  }
}
```

## Edge Cases

### Case 1: Duplicate Images

- Если пользователь пытается добавить дубликат URL
- Проверить перед добавлением
- Показать сообщение "Image already exists"

### Case 2: Invalid URL

- Если URL невалиден или изображение не загружается
- Показать ошибку
- Не сохранять в БД

### Case 3: Deleted Default Image

- Если пользователь удалил дефолтное изображение
- При следующей загрузке восстановить из DEFAULT_IMAGES
- Или не разрешать удаление дефолтных изображений
