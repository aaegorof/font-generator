# Story 9.1: Font Upload to Storage

## Description

Мигрировать загрузку шрифтов с локального Express сервера на Supabase Storage. Реализовать загрузку файлов шрифтов в bucket `user-fonts`, генерацию публичных URL и инжекцию `@font-face` с новыми URL.

## User Story

**As a** авторизованный пользователь  
**I want** загружать шрифты в облачное хранилище  
**So that** они были доступны с любого устройства

## Goals

- Загружать файлы шрифтов в Supabase Storage bucket `user-fonts`
- Генерировать публичные URL для загруженных шрифтов
- Инжектировать `@font-face` с URL из Storage
- Обновить метаданные шрифта в таблице `user_fonts`
- Сохранить обратную совместимость с существующим UI

## Acceptance Criteria

### Must Have

- [ ] Файлы шрифтов загружаются в Supabase Storage (`user-fonts/{user_id}/{font_id}.{ext}`)
- [ ] Генерируется публичный URL для каждого шрифта
- [ ] `@font-face` инжектируется с URL из Storage
- [ ] Метаданные шрифта сохраняются в `user_fonts` таблице
- [ ] `storage_path` заполняется в `user_fonts`
- [ ] Загруженные шрифты отображаются в UI
- [ ] Поддерживаются форматы: `.woff2`, `.woff`, `.ttf`

### Should Have

- [ ] Валидация размера файла (max 5 MB)
- [ ] Валидация типа файла
- [ ] Progress indicator во время загрузки
- [ ] Обработка ошибок загрузки

### Font Upload Service

Обновить `src/services/fontSync.ts`:

```typescript
import { supabase } from '../lib/supabase'
import type { FontDef } from '../types'

export class FontSyncService {
  // ... existing methods ...

  /**
   * Upload font file to Supabase Storage
   */
  static async uploadFont(
    userId: string,
    file: File,
    fontId: string,
  ): Promise<{ url: string; storagePath: string }> {
    try {
      // Validate file
      this.validateFontFile(file)

      // Generate storage path
      const fileExt = file.name.split('.').pop()
      const storagePath = `${userId}/${fontId}.${fileExt}`

      // Upload to Storage
      const { data, error } = await supabase.storage.from('user-fonts').upload(storagePath, file, {
        cacheControl: '3600',
        upsert: false,
      })

      if (error) throw error

      // Get public URL
      const { data: urlData } = supabase.storage.from('user-fonts').getPublicUrl(storagePath)

      return {
        url: urlData.publicUrl,
        storagePath: storagePath,
      }
    } catch (err) {
      console.error('Error uploading font:', err)
      throw err
    }
  }

  /**
   * Delete font file from Storage
   */
  static async deleteFontFile(storagePath: string): Promise<void> {
    try {
      const { error } = await supabase.storage.from('user-fonts').remove([storagePath])

      if (error) throw error
    } catch (err) {
      console.error('Error deleting font file:', err)
      throw err
    }
  }

  /**
   * Validate font file
   */
  private static validateFontFile(file: File): void {
    // Check file size (max 5 MB)
    const maxSize = 5 * 1024 * 1024
    if (file.size > maxSize) {
      throw new Error('Font file too large (max 5 MB)')
    }

    // Check file type
    const allowedExtensions = ['woff2', 'woff', 'ttf']
    const fileExt = file.name.split('.').pop()?.toLowerCase()

    if (!fileExt || !allowedExtensions.includes(fileExt)) {
      throw new Error('Invalid font file type (allowed: .woff2, .woff, .ttf)')
    }
  }

  /**
   * Save font with storage metadata
   */
  static async saveFontWithFile(userId: string, font: FontDef, file: File): Promise<void> {
    try {
      // Upload file to Storage
      const { url, storagePath } = await this.uploadFont(userId, file, font.id)

      // Update font definition
      const fontWithUrl: FontDef = {
        ...font,
        uploadUrl: url,
        fileName: file.name,
        source: 'uploaded',
      }

      // Save to database
      const { error } = await supabase.from('user_fonts').insert({
        user_id: userId,
        font_def: fontWithUrl,
        storage_path: storagePath,
      })

      if (error) throw error
    } catch (err) {
      console.error('Error saving font with file:', err)
      throw err
    }
  }

  /**
   * Delete font with file
   */
  static async deleteFontWithFile(userId: string, fontId: string): Promise<void> {
    try {
      // Get storage path from database
      const { data, error: fetchError } = await supabase
        .from('user_fonts')
        .select('storage_path')
        .eq('user_id', userId)
        .eq('font_def->id', fontId)
        .single()

      if (fetchError) throw fetchError

      // Delete from database
      await this.deleteFont(userId, fontId)

      // Delete file from Storage if exists
      if (data?.storage_path) {
        await this.deleteFontFile(data.storage_path)
      }
    } catch (err) {
      console.error('Error deleting font with file:', err)
      throw err
    }
  }
}
```

### Update FontsPage Component

Обновить `src/pages/FontsPage.tsx`:

```typescript
import { FontSyncService } from '../services/fontSync'
import { getCurrentUserId } from '../utils/auth'

const handleFileUpload = async (file: File) => {
  try {
    setUploading(true)
    setError(null)

    const userId = await getCurrentUserId()
    if (!userId) {
      throw new Error('User not authenticated')
    }

    // Generate font ID
    const fontId = `font-${Date.now()}-${Math.random().toString(36).substr(2, 9)}`

    // Extract font name from filename
    const fontName = file.name.replace(/\.(woff2|woff|ttf)$/i, '')

    // Create font definition
    const font: FontDef = {
      id: fontId,
      name: fontName,
      source: 'uploaded',
      isActive: true,
    }

    // Upload font with file
    await FontSyncService.saveFontWithFile(userId, font, file)

    // Add to store (will trigger sync)
    addFont(font)

    // Inject @font-face
    injectUploadedFont(font)

    setUploading(false)
  } catch (err) {
    console.error('Error uploading font:', err)
    setError(err instanceof Error ? err.message : 'Upload failed')
    setUploading(false)
  }
}
```

### Font Face Injection

Обновить `src/utils/fonts.ts`:

```typescript
export function injectUploadedFont(font: FontDef) {
  if (!font.uploadUrl) return

  const fontFaceRule = `
    @font-face {
      font-family: '${font.name}';
      src: url('${font.uploadUrl}') format('${getFontFormat(font.uploadUrl)}');
      font-display: swap;
    }
  `

  const styleId = `font-${font.id}`
  let styleEl = document.getElementById(styleId) as HTMLStyleElement

  if (!styleEl) {
    styleEl = document.createElement('style')
    styleEl.id = styleId
    document.head.appendChild(styleEl)
  }

  styleEl.textContent = fontFaceRule
}

function getFontFormat(url: string): string {
  if (url.endsWith('.woff2')) return 'woff2'
  if (url.endsWith('.woff')) return 'woff'
  if (url.endsWith('.ttf')) return 'truetype'
  return 'woff2' // default
}

export function removeUploadedFont(fontId: string) {
  const styleEl = document.getElementById(`font-${fontId}`)
  if (styleEl) {
    styleEl.remove()
  }
}
```

const loadUserData = async (userId: string) => {
  try {
    // ... existing code ...

    // Load fonts
    const fonts = await FontSyncService.loadFonts(userId)
    const store = useStore.getState()

    // Merge with default fonts
    const allFonts = [...DEFAULT_FONTS, ...fonts]

    // Update store and inject uploaded fonts
    allFonts.forEach((font) => {
      if (!store.fonts.find((f) => f.id === font.id)) {
        store.addFont(font)

        // Inject @font-face for uploaded fonts
        if (font.source === 'uploaded' && font.uploadUrl) {
          injectUploadedFont(font)
        }
      }
    })
  } catch (err) {
    console.error('Error loading user data:', err)
  }
}

## Edge Cases

### Case 1: Duplicate Filename

- Если файл с таким именем уже существует
- Использовать `upsert: false` чтобы предотвратить перезапись
- Показать ошибку пользователю

### Case 2: Upload Failure

- Если загрузка не удалась (сеть, права доступа)
- Показать ошибку
- Не создавать запись в `user_fonts`
- Retry опция для пользователя

### Case 3: Orphaned Files

- Если запись в БД удалена, но файл остался в Storage
- Реализовать cleanup job (future)
- Или использовать RLS policies для автоматического удаления

### Case 4: Missing Storage Path

- Если в БД нет `storage_path` для uploaded font
- Показать ошибку в UI
- Не пытаться загрузить файл

## Performance Considerations

### Optimization Strategies

1. **Compression**: Предпочитать .woff2 формат (лучшее сжатие)
2. **Caching**: Использовать `cacheControl: '3600'` для кэширования
3. **Lazy Loading**: Загружать шрифты по требованию (future)
4. **Progress Tracking**: Показывать прогресс загрузки для больших файлов

### Storage Limits

- Max file size: 5 MB (настраивается)
- Bucket size: Unlimited (зависит от Supabase плана)
- RLS policies: Защищают от несанкционированного доступа
