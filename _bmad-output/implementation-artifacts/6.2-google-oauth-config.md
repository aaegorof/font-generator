## Technical Details

### Google Cloud Console Setup

#### Step 1: Create Project

1. Перейти на [Google Cloud Console](https://console.cloud.google.com/)
2. Создать новый проект: "Font Generator"
3. Выбрать проект

#### Step 2: Enable Google+ API

1. Navigation Menu → APIs & Services → Library
2. Найти "Google+ API"
3. Нажать "Enable"

#### Step 3: Configure OAuth Consent Screen

1. APIs & Services → OAuth consent screen
2. Выбрать "External" (для тестирования)
3. Заполнить форму:
   - **App name**: Font Generator
   - **User support email**: ваш email
   - **Developer contact email**: ваш email
4. Scopes: добавить `email`, `profile`, `openid`
5. Test users: добавить свой Gmail для тестирования
6. Сохранить

#### Step 4: Create OAuth 2.0 Credentials

1. APIs & Services → Credentials
2. Create Credentials → OAuth 2.0 Client ID
3. Application type: "Web application"
4. Name: "Font Generator Web Client"
5. Authorized JavaScript origins:
   ```
   http://localhost:5173
   http://localhost:3000
   ```
6. Authorized redirect URIs:
   ```
   http://localhost:8000/auth/v1/callback
   http://localhost:5173/auth/callback
   ```
7. Create
8. Скопировать **Client ID** и **Client Secret**

### Supabase Configuration

#### Update .env File

```bash
# Google OAuth
ENABLE_GOOGLE_OAUTH=true
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-client-secret

# Site URL (frontend)
SITE_URL=http://localhost:5173
API_EXTERNAL_URL=http://localhost:8000

# Additional redirect URLs (comma separated)
ADDITIONAL_REDIRECT_URLS=http://localhost:5173/**
```

#### Restart Supabase Services

```bash
# Restart auth service to pick up new env vars
docker-compose restart auth

# Check logs
docker-compose logs -f auth
```

### Supabase Studio Configuration

1. Открыть Supabase Studio: `http://localhost:3000`
2. Authentication → Providers
3. Найти "Google"
4. Enable
5. Ввести Client ID и Client Secret
6. Redirect URL: `http://localhost:8000/auth/v1/callback`
7. Save

### OAuth Flow

```
User clicks "Sign in with Google"
  ↓
Redirect to Supabase Auth: /auth/v1/authorize?provider=google
  ↓
Supabase redirects to Google OAuth
  ↓
User authorizes in Google
  ↓
Google redirects to: http://localhost:8000/auth/v1/callback
  ↓
Supabase processes callback and creates session
  ↓
Redirect to frontend: http://localhost:5173/auth/callback
  ↓
Frontend extracts access_token from URL hash
  ↓
User is authenticated
```

    GOTRUE_EXTERNAL_GOOGLE_CLIENT_ID: ${GOOGLE_CLIENT_ID}
    GOTRUE_EXTERNAL_GOOGLE_SECRET: ${GOOGLE_CLIENT_SECRET}

## Troubleshooting

### Issue: "redirect_uri_mismatch"

**Solution:** Проверить, что redirect URI в Google Console точно совпадает с `${API_EXTERNAL_URL}/auth/v1/callback`

### Issue: "invalid_client"

**Solution:** Проверить, что Client ID и Secret правильно скопированы в `.env`

### Issue: Auth service не стартует

**Solution:** Проверить логи:

```bash
docker-compose logs auth
```

### Issue: Google OAuth screen показывает "App not verified"

**Solution:** Это нормально для development. Нажать "Advanced" → "Go to Font Generator (unsafe)"
