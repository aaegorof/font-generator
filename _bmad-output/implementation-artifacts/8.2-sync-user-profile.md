# Story 8.2: Sync User Profile

## Description

Реализовать синхронизацию основных настроек пользователя (settings, textInputs, toolbarOpen, layerFontPins, disabledImages) между Zustand store и Supabase таблицей `user_profiles`.

## User Story

**As a** авторизованный пользователь  
**I want** чтобы мои настройки (колонки, padding, текстовые слои) синхронизировались с облаком  
**So that** я мог работать с разных устройств с одинаковыми настройками

- Обеспечить двустороннюю синхронизацию (load и save)

### Enhanced Sync Hook

Обновить `src/hooks/useSupabaseSync.ts`:

```typescript
const saveToSupabase = async (userId: string, state: any) => {
  setSyncing(true)
  setError(null)

  try {
    // Validate data before saving
    validateUserProfile(state)

    const { error: saveError } = await supabase
      .from('user_profiles')
      .update({
        settings: state.settings,
        text_inputs: state.textInputs,
        toolbar_open: state.toolbarOpen,
        layer_font_pins: state.layerFontPins,
        disabled_images: state.disabledImages,
        updated_at: new Date().toISOString(),
      })
      .eq('id', userId)

    if (saveError) throw saveError

    setLastSynced(new Date())
  } catch (err) {
    console.error('Error saving to Supabase:', err)
    setError(err as Error)
  } finally {
    setSyncing(false)
  }
}

const loadFromSupabase = async (userId: string) => {
  try {
    const { data, error: loadError } = await supabase
      .from('user_profiles')
      .select('settings, text_inputs, toolbar_open, layer_font_pins, disabled_images, updated_at')
      .eq('id', userId)
      .single()

    if (loadError) throw loadError
    if (!data) return

    // Update store with loaded data
    const store = useStore.getState()

    if (data.settings) {
      store.updateSettings(data.settings)
    }

    if (data.text_inputs && Array.isArray(data.text_inputs)) {
      // Replace all text inputs
      const currentInputs = store.textInputs
      currentInputs.forEach((input) => store.removeTextInput(input.id))
      data.text_inputs.forEach((input) => {
        // Add text input with loaded data
        store.addTextInput()
        const newInputId = store.textInputs[store.textInputs.length - 1].id
        store.updateTextInput(newInputId, input)
      })
    }

    if (typeof data.toolbar_open === 'boolean') {
      if (data.toolbar_open !== store.toolbarOpen) {
        store.toggleToolbar()
      }
    }

    if (data.layer_font_pins && typeof data.layer_font_pins === 'object') {
      // Clear existing pins
      Object.keys(store.layerFontPins).forEach((key) => {
        store.setLayerFontPin(Number(key), null)
      })
      // Set loaded pins
      Object.entries(data.layer_font_pins).forEach(([key, value]) => {
        store.setLayerFontPin(Number(key), value as string)
      })
    }

    if (data.disabled_images && Array.isArray(data.disabled_images)) {
      // Sync disabled images
      data.disabled_images.forEach((url) => {
        if (!store.disabledImages.includes(url)) {
          store.toggleImageDisabled(url)
        }
      })
    }

    setLastSynced(new Date(data.updated_at))
  } catch (err) {
    console.error('Error loading from Supabase:', err)
    setError(err as Error)
  }
}
```

### Data Validation

Создать `src/utils/validation.ts`:

```typescript
export function validateUserProfile(state: any) {
  // Validate settings
  if (!state.settings || typeof state.settings !== 'object') {
    throw new Error('Invalid settings')
  }

  if (typeof state.settings.columns !== 'number' || state.settings.columns < 1) {
    throw new Error('Invalid columns value')
  }

  if (typeof state.settings.padding !== 'number' || state.settings.padding < 0) {
    throw new Error('Invalid padding value')
  }

  if (
    typeof state.settings.overlayOpacity !== 'number' ||
    state.settings.overlayOpacity < 0 ||
    state.settings.overlayOpacity > 1
  ) {
    throw new Error('Invalid overlayOpacity value')
  }

  if (typeof state.settings.grayscale !== 'boolean') {
    throw new Error('Invalid grayscale value')
  }

  // Validate text inputs
  if (!Array.isArray(state.textInputs)) {
    throw new Error('Invalid textInputs')
  }

  state.textInputs.forEach((input: any, index: number) => {
    if (!input.id || typeof input.id !== 'string') {
      throw new Error(`Invalid textInput id at index ${index}`)
    }
    if (typeof input.text !== 'string') {
      throw new Error(`Invalid textInput text at index ${index}`)
    }
    if (typeof input.fontSize !== 'number' || input.fontSize <= 0) {
      throw new Error(`Invalid textInput fontSize at index ${index}`)
    }
  })

  // Validate other fields
  if (typeof state.toolbarOpen !== 'boolean') {
    throw new Error('Invalid toolbarOpen')
  }

  if (typeof state.layerFontPins !== 'object') {
    throw new Error('Invalid layerFontPins')
  }

  if (!Array.isArray(state.disabledImages)) {
    throw new Error('Invalid disabledImages')
  }
}
```

### Logout Handler

При logout `useSupabaseSync` автоматически:
- Сбрасывает флаг `initialLoadComplete`
- Отменяет все pending сохранения
- Очищает состояние синхронизации
- localStorage снова становится активным для неавторизованных пользователей

Никаких дополнительных действий в `useAuth.ts` не требуется - все обрабатывается автоматически через `useEffect` dependency на `userId`.

## Edge Cases

### Case 1: Empty Text Inputs

- Если пользователь удалил все текстовые слои
- Сохранить пустой массив в БД
- При загрузке создать дефолтный слой

### Case 2: Invalid Data in Database

- Если в БД попали невалидные данные
- Показать ошибку и использовать defaults
- Логировать проблему для отладки

### Case 3: Partial Data

- Если в БД только часть данных
- Использовать defaults для отсутствующих полей
- Не перезаписывать существующие данные

## Notes

### Data Storage

- **Supabase (PostgreSQL JSONB)** = единственный источник правды для авторизованных пользователей
  - JSONB позволяет хранить сложные структуры данных (objects, arrays)
  - Автоматическая очистка localStorage после загрузки из базы
  - Нет конфликтов между локальным и облачным хранилищем
  
- **localStorage** = используется только для неавторизованных пользователей
  - Автоматически через Zustand persist middleware
  - При авторизации данные из localStorage игнорируются

### Data Integrity

- Валидация важна для предотвращения сохранения невалидных данных
- При изменении схемы данных нужно будет добавить миграцию
- Используется `validateUserProfile()` перед каждым сохранением
