# Story 7.2: Create Auth Hook

## Description

Создать React hook `useAuth` для управления состоянием авторизации пользователя. Hook должен предоставлять методы для входа/выхода через Google OAuth, отслеживать состояние авторизации и предоставлять информацию о текущем пользователе.

## User Story

**As a** разработчик  
**I want** иметь централизованный hook для управления авторизацией  
**So that** компоненты могут легко получать доступ к состоянию авторизации и методам входа/выхода

## Goals

- Создать `useAuth` hook с полным функционалом авторизации
- Реализовать sign in через Google OAuth
- Реализовать sign out
- Отслеживать изменения состояния авторизации
- Предоставлять информацию о текущем пользователе

## Technical Details

### Hook Interface

```typescript
interface UseAuthReturn {
  user: User | null
  session: Session | null
  loading: boolean
  signInWithGoogle: () => Promise<void>
  signOut: () => Promise<void>
  error: Error | null
}

export function useAuth(): UseAuthReturn
```

### Implementation (`src/hooks/useAuth.ts`)

```typescript
import { useState, useEffect } from 'react'
import { supabase } from '../lib/supabase'
import type { User, Session } from '@supabase/supabase-js'

export interface UseAuthReturn {
  user: User | null
  session: Session | null
  loading: boolean
  signInWithGoogle: () => Promise<void>
  signOut: () => Promise<void>
  error: Error | null
}

export function useAuth(): UseAuthReturn {
  const [user, setUser] = useState<User | null>(null)
  const [session, setSession] = useState<Session | null>(null)
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState<Error | null>(null)

  useEffect(() => {
    // Get initial session
    supabase.auth.getSession().then(({ data: { session } }) => {
      setSession(session)
      setUser(session?.user ?? null)
      setLoading(false)
    })

    // Listen for auth changes
    const {
      data: { subscription },
    } = supabase.auth.onAuthStateChange((_event, session) => {
      setSession(session)
      setUser(session?.user ?? null)
      setLoading(false)
    })

    return () => subscription.unsubscribe()
  }, [])

  const signInWithGoogle = async () => {
    try {
      setError(null)
      const { error } = await supabase.auth.signInWithOAuth({
        provider: 'google',
        options: {
          redirectTo: window.location.origin,
        },
      })
      if (error) throw error
    } catch (err) {
      setError(err as Error)
      console.error('Error signing in with Google:', err)
    }
  }

  const signOut = async () => {
    try {
      setError(null)
      const { error } = await supabase.auth.signOut()
      if (error) throw error
    } catch (err) {
      setError(err as Error)
      console.error('Error signing out:', err)
    }
  }

  return {
    user,
    session,
    loading,
    signInWithGoogle,
    signOut,
    error,
  }
}
```

### Auth State Changes

Hook отслеживает следующие события:
- `SIGNED_IN` — пользователь вошел
- `SIGNED_OUT` — пользователь вышел
- `TOKEN_REFRESHED` — токен обновлен
- `USER_UPDATED` — данные пользователя обновлены

### Google OAuth Flow

1. Пользователь вызывает `signInWithGoogle()`
2. Supabase перенаправляет на Google OAuth
3. После авторизации Google перенаправляет обратно в приложение
4. Supabase обрабатывает callback и создает сессию
5. Hook автоматически обновляет состояние через `onAuthStateChange`

### Redirect Handling

Supabase автоматически обрабатывает OAuth callback благодаря настройке:
- `detectSessionInUrl: true` в конфигурации клиента
- Redirect URL настроен в Story 6.2

## Error Handling

### Common Errors

1. **Missing environment variables**
   ```typescript
   Error: Missing VITE_SUPABASE_ANON_KEY
   ```
   → Проверить `.env.local`

2. **OAuth configuration error**
   ```typescript
   Error: Invalid redirect URL
   ```
   → Проверить настройки в Story 6.2

3. **Network error**
   ```typescript
   Error: Failed to fetch
   ```
   → Проверить что Supabase Docker контейнеры запущены
