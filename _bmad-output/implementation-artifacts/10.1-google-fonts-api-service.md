## Overview

## Key Features

### API Integration
- Uses native `fetch` API with async/await
- Endpoint: `https://www.googleapis.com/webfonts/v1/webfonts?key={API_KEY}`
- Returns array of Google Font families with metadata

### Caching Strategy
- In-memory cache for session duration
- Cache key: `googleFontsCache` module-level variable
- Reduces API calls and improves performance
- Cache can be cleared manually via `clearFontCache()`

### Error Handling
Comprehensive error handling for:
- **Missing API Key** - Graceful degradation with console warning
- **HTTP 400** - Invalid API key error
- **HTTP 429** - Rate limit exceeded error
- **Network Errors** - Connection issues
- **Invalid Response** - Unexpected API response structure
- **Generic Errors** - Any other unexpected errors

All errors return empty array `[]` and log appropriate console warnings/errors.

### Manual Testing

To test the service:

1. Get a Google Fonts API key from [Google Cloud Console](https://console.cloud.google.com/apis/credentials)
2. Enable the Web Fonts Developer API
3. Add to `.env.local`:
   ```
   VITE_GOOGLE_FONTS_API_KEY=your-api-key-here
   ```
4. Test in browser console:
   ```javascript
   import { fetchFontList } from './services/googleFontsApi'
   const fonts = await fetchFontList()
   console.log(fonts.length) // Should show 1000+
   ```

## Technical Notes

### Environment Variables
- Uses Vite's `import.meta.env` for environment variable access
- Variable name: `VITE_GOOGLE_FONTS_API_KEY`
- Prefix `VITE_` makes it available in client-side code

### Performance Considerations
- API response is ~100KB (1000+ fonts)
- Cached after first fetch (no repeated API calls)
- Cache persists for session duration (page refresh clears cache)

### Security
- API key is read-only and scoped to specific domain
- No server-side proxy needed (Google Fonts API allows CORS)
- API key exposure is low risk (standard practice for Google Fonts)

## Dependencies

### External
- Google Fonts Web API v1
- Requires API key from Google Cloud Console

### Internal
- None (self-contained service)

## Known Limitations

1. **No offline support** - Requires network connection to fetch fonts
2. **Session-level cache** - Cache clears on page refresh
3. **No automatic retry** - Failed requests return empty array immediately
4. **No rate limit handling** - If rate limited, user must wait until limit resets
