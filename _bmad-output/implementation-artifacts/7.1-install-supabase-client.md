## Technical Details

### Dependencies to Install

```bash
npm install @supabase/supabase-js@^2
npm install @supabase/auth-ui-react@^0.4
npm install @supabase/auth-ui-shared@^0.1
```

### Supabase Client (`src/lib/supabase.ts`)

```typescript
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = import.meta.env.VITE_SUPABASE_URL || 'http://127.0.0.1:54321'
const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY

if (!supabaseAnonKey) {
  throw new Error('Missing VITE_SUPABASE_ANON_KEY environment variable')
}

export const supabase = createClient(supabaseUrl, supabaseAnonKey, {
  auth: {
    autoRefreshToken: true,
    persistSession: true,
    detectSessionInUrl: true,
  },
})
```

### Environment Variables

**`.env.local`** (не коммитить):

```bash
# Supabase Configuration
VITE_SUPABASE_URL=http://127.0.0.1:54321
VITE_SUPABASE_ANON_KEY=<your-anon-key-from-supabase>

# Google OAuth (from Story 6.2)
VITE_GOOGLE_CLIENT_ID=<your-google-client-id>
```

**`.env.example`** (коммитить):

```bash
# Supabase Configuration
VITE_SUPABASE_URL=http://127.0.0.1:54321
VITE_SUPABASE_ANON_KEY=your-anon-key-here

# Google OAuth
VITE_GOOGLE_CLIENT_ID=your-google-client-id-here
```

### Getting Anon Key

Anon key можно получить из:

1. Supabase Studio → Settings → API
2. Или из `.env` файла в корне проекта (переменная `ANON_KEY`)

### TypeScript Types

Supabase автоматически предоставляет TypeScript типы. Для дополнительной типизации можно создать `src/types/supabase.ts`:

```typescript
import { Session, User } from '@supabase/supabase-js'

export type { Session, User }

// Database types (will be extended in future stories)

          layer_font_pins: any
          disabled_images: any
          created_at: string
          updated_at: string
        }
      }
      // ... other tables
    }
  }
}
```
