# Story 7.1: Install Supabase Client

## Description

Установить Supabase JavaScript клиент и необходимые зависимости для интеграции авторизации в React приложение. Создать базовую конфигурацию Supabase client и настроить environment variables.

## User Story

**As a** разработчик  
**I want** установить и настроить Supabase клиент  
**So that** приложение может взаимодействовать с Supabase backend

## Goals

- Установить необходимые npm пакеты для Supabase
- Создать файл инициализации Supabase client
- Настроить environment variables для подключения
- Проверить корректность подключения

## Technical Details

### Dependencies to Install

```bash
npm install @supabase/supabase-js@^2
npm install @supabase/auth-ui-react@^0.4
npm install @supabase/auth-ui-shared@^0.1
```

### Supabase Client (`src/lib/supabase.ts`)

```typescript
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = import.meta.env.VITE_SUPABASE_URL || 'http://127.0.0.1:54321'
const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY

if (!supabaseAnonKey) {
  throw new Error('Missing VITE_SUPABASE_ANON_KEY environment variable')
}

export const supabase = createClient(supabaseUrl, supabaseAnonKey, {
  auth: {
    autoRefreshToken: true,
    persistSession: true,
    detectSessionInUrl: true,
  },
})
```

### Environment Variables

**`.env.local`** (не коммитить):
```bash
# Supabase Configuration
VITE_SUPABASE_URL=http://127.0.0.1:54321
VITE_SUPABASE_ANON_KEY=<your-anon-key-from-supabase>

# Google OAuth (from Story 6.2)
VITE_GOOGLE_CLIENT_ID=<your-google-client-id>
```

**`.env.example`** (коммитить):
```bash
# Supabase Configuration
VITE_SUPABASE_URL=http://127.0.0.1:54321
VITE_SUPABASE_ANON_KEY=your-anon-key-here

# Google OAuth
VITE_GOOGLE_CLIENT_ID=your-google-client-id-here
```

### Getting Anon Key

Anon key можно получить из:
1. Supabase Studio → Settings → API
2. Или из `.env` файла в корне проекта (переменная `ANON_KEY`)

## Implementation Steps

### Step 1: Install Dependencies

```bash
npm install @supabase/supabase-js@^2 @supabase/auth-ui-react@^0.4 @supabase/auth-ui-shared@^0.1
```

### Step 2: Create Supabase Client

Создать файл `src/lib/supabase.ts` с инициализацией клиента.

### Step 3: Setup Environment Variables

1. Создать `.env.local` с реальными значениями
2. Обновить `.env.example` с placeholder значениями
3. Убедиться что `.env.local` в `.gitignore`

### Step 4: Verify Connection

Создать простой тест в консоли браузера:

```typescript
import { supabase } from './lib/supabase'

// Test connection
const { data, error } = await supabase.auth.getSession()
console.log('Supabase connection:', { data, error })
```

## Testing

### Manual Testing

1. Запустить приложение: `npm run dev`
2. Открыть DevTools Console
3. Проверить что нет ошибок подключения к Supabase
4. Выполнить тестовый запрос к Supabase API
