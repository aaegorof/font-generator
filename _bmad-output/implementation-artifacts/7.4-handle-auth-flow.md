# Story 7.4: Handle Auth Flow

## Description

Реализовать полный flow авторизации: обработка OAuth callback после редиректа от Google, загрузка пользовательских данных из Supabase после успешного логина, обработка ошибок и edge cases.

## User Story

**As a** пользователь  
**I want** чтобы после авторизации через Google я автоматически вернулся в приложение с загруженными данными  
**So that** я мог сразу начать работу без дополнительных действий

## Goals

- Обработать OAuth callback после редиректа от Google
- Загрузить пользовательские данные из Supabase после логина
- Создать user profile если это первый вход
- Обработать ошибки авторизации
- Обеспечить плавный UX во время auth flow

## Acceptance Criteria

### Must Have
- [ ] OAuth callback корректно обрабатывается после редиректа от Google
- [ ] После успешного логина загружаются данные пользователя из БД
- [ ] Если пользователь новый — создается запись в `user_profiles`
- [ ] При логауте данные очищаются из store
- [ ] Ошибки авторизации отображаются пользователю
- [ ] URL очищается от OAuth параметров после обработки

### Should Have
- [ ] Loading indicator во время обработки callback
- [ ] Уведомление об успешном входе/выходе
- [ ] Graceful fallback при ошибках

## Technical Details

### Auth Flow Sequence

```
1. User clicks "Sign in with Google"
   ↓
2. Redirect to Google OAuth
   ↓
3. User authorizes in Google
   ↓
4. Google redirects back with code/token
   ↓
5. Supabase exchanges code for session
   ↓
6. App detects session change
   ↓
7. Load user data from database
   ↓
8. Create profile if first login
   ↓
9. Update Zustand store
   ↓
10. Show success message
```

### Auth Callback Handler

Создать `src/hooks/useAuthCallback.ts`:

```typescript
import { useEffect, useState } from 'react'
import { useNavigate } from 'react-router-dom'
import { supabase } from '../lib/supabase'

export function useAuthCallback() {
  const [processing, setProcessing] = useState(false)
  const [error, setError] = useState<string | null>(null)
  const navigate = useNavigate()

  useEffect(() => {
    // Check if we're handling an OAuth callback
    const hashParams = new URLSearchParams(window.location.hash.substring(1))
    const accessToken = hashParams.get('access_token')
    
    if (accessToken) {
      handleCallback()
    }
  }, [])

  const handleCallback = async () => {
    setProcessing(true)
    setError(null)

    try {
      // Supabase automatically handles the callback
      const { data: { session }, error: sessionError } = await supabase.auth.getSession()
      
      if (sessionError) throw sessionError
      if (!session) throw new Error('No session after callback')

      // Clean up URL
      window.history.replaceState({}, document.title, window.location.pathname)
      
      setProcessing(false)
    } catch (err) {
      console.error('Auth callback error:', err)
      setError(err instanceof Error ? err.message : 'Authentication failed')
      setProcessing(false)
    }
  }

  return { processing, error }
}
```

### User Data Loader

Создать `src/hooks/useUserData.ts`:

```typescript
import { useEffect } from 'react'
import { useStore } from '../store/useStore'
import { supabase } from '../lib/supabase'
import type { User } from '@supabase/supabase-js'

export function useUserData(user: User | null) {
  const importAllSettings = useStore((s) => s.importAllSettings)

  useEffect(() => {
    if (!user) {
      // Clear store on logout
      // Will be implemented in Story 8.2
      return
    }

    loadUserData(user.id)
  }, [user])

  const loadUserData = async (userId: string) => {
    try {
      // Check if profile exists
      const { data: profile, error: profileError } = await supabase
        .from('user_profiles')
        .select('*')
        .eq('id', userId)
        .single()

      if (profileError && profileError.code !== 'PGRST116') {
        // PGRST116 = not found, which is OK for first login
        throw profileError
      }

      if (!profile) {
        // First login - create profile with default data
        await createUserProfile(userId)
      } else {
        // Load existing data into store
        // Will be implemented in Story 8.2
        console.log('User profile loaded:', profile)
      }
    } catch (err) {
      console.error('Error loading user data:', err)
    }
  }

  const createUserProfile = async (userId: string) => {
    try {
      const { error } = await supabase
        .from('user_profiles')
        .insert({
          id: userId,
          settings: {
            columns: 4,
            padding: 24,
            overlayOpacity: 0.25,
            grayscale: false,
          },
          text_inputs: [{
            id: 'input-default-1',
            text: 'de Tribe',
            fontSize: 56,
            letterSpacing: 0.02,
            lineHeight: 1.0,
            textColor: '#ffffff',
            textShadow: true,
            textWrap: true,
            alignment: 'center',
            verticalAlignment: 'center',
          }],
          toolbar_open: true,
          layer_font_pins: {},
          disabled_images: [],
        })

      if (error) throw error
      console.log('User profile created')
    } catch (err) {
      console.error('Error creating user profile:', err)
      throw err
    }
  }
}
```

```typescript
function App() {
  const { user, loading } = useAuth()
  const { processing, error: callbackError } = useAuthCallback()
  useUserData(user)

  if (loading || processing) {
    return <div>Loading...</div>
  }

  if (callbackError) {
    return <div>Error: {callbackError}</div>
  }

  return (
    // ... rest of app
  )
}
```

### Error Handling

Обработка различных ошибок:

```typescript
interface AuthError {
  code: string
  message: string
}

function handleAuthError(error: AuthError) {
  switch (error.code) {
    case 'invalid_grant':
      return 'Invalid authorization code. Please try again.'
    case 'access_denied':
      return 'Access denied. You must authorize the app to continue.'
    case 'server_error':
      return 'Server error. Please try again later.'
    default:
      return error.message || 'Authentication failed'
  }
}
```

## Edge Cases

### Case 1: Multiple Tabs
- Если пользователь авторизуется в одной вкладке, другие вкладки должны обновиться
- Supabase автоматически синхронизирует сессию через localStorage events

### Case 2: Expired Session
- Если session истек, Supabase автоматически обновит токен
- Если refresh не удался, пользователь будет разлогинен

### Case 3: Network Errors
- При ошибках сети показывать retry опцию
- Сохранять состояние для повторной попытки

### Case 4: Concurrent Requests
- Использовать debouncing для предотвращения дублирующих запросов
- Supabase client автоматически управляет concurrent auth requests
