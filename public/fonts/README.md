# Custom Fonts

Place your font files in this folder to activate them in the app.

## Expected file names

| Font name     | Expected file names                                  |
|---------------|------------------------------------------------------|
| Collidge Bold | `Collidge-Bold.woff2`, `Collidge-Bold.woff`, `Collidge-Bold.ttf` |
| Radeil 3D     | `Radeil3D.woff2`, `Radeil3D.woff`, `Radeil3D.ttf`   |
| Wilker        | `Wilker.woff2`, `Wilker.woff`, `Wilker.ttf`          |
| Codec Pro     | `CodecPro.woff2`, `CodecPro.woff`, `CodecPro.ttf`    |
| Portico       | `Portico.woff2`, `Portico.woff`, `Portico.ttf`       |
| Gibson        | `Gibson.woff2`, `Gibson.woff`, `Gibson.ttf`          |

## Supported formats

`.woff2` (preferred), `.woff`, `.ttf`, `.otf`

## Adding new fonts via UI

You can also upload fonts directly through the app UI:
1. Open the **Fonts** tab in the toolbar
2. Click **Upload Font File**
3. Select your `.woff2` / `.ttf` file

The font will be available immediately without restart.
