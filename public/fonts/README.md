# Custom Fonts (Deprecated)

⚠️ **This folder is no longer used for local font storage.**

All font uploads now go through **Supabase Storage** and are stored in the cloud. This allows your fonts to be available across all devices.

## Uploading Fonts

To upload custom fonts:
1. Sign in to the app
2. Open the **Fonts** tab in the toolbar
3. Click **Upload Font File**
4. Select your `.woff2` / `.ttf` / `.otf` file

Your fonts will be stored in Supabase Storage and available immediately on all your devices.

## Supported Formats

`.woff2` (preferred), `.woff`, `.ttf`, `.otf`
